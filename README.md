**FashionCart** is a modern, responsive, and feature-rich e-commerce web application designed for fashion enthusiasts. It offers a seamless online shopping experience with interactive product catalogs, dedicated category sections (Men, Women, Kids, Footwear), interactive cart & checkout workflows, user profile management, and smooth UI animations.

---

## ✨ Features

- **🏠 Interactive Homepage (`index.html`)**: Dynamic hero carousel, trending categories, top picks, promotional banners, and newsletter subscription.
- **🛒 Product Catalog & Shop (`shop.html`)**: Rich product grid with filtering options, search capabilities, and sorting options.
- **👕 Men's Fashion (`mens.html`)**: Dedicated catalog showcasing men's apparel, casual wear, formal suits, and accessories.
- **👗 Women's Fashion (`womens.html`)**: Curated collections featuring ethnic wear (sarees, kurtis), western dresses, and modern fashion trends.
- **🧒 Kids' Collection (`kids.html`)**: Fashion catalog designed for boys and girls with vibrant category sections.
- **👟 Footwear Hub (`footwear.html`)**: Comprehensive footwear catalog including sneakers, sports shoes, formal shoes, and traditional footwear.
- **🛍️ Shopping Cart (`cart.html`)**: Dynamic cart summary, quantity adjustments, item removal, and subtotal calculation.
- **💳 Checkout Flow (`checkout.html`)**: Comprehensive order summary, shipping address forms, and multi-payment option support.
- **❤️ Wishlist Management (`wishlist.html`)**: Save favorite products for future purchases.
- **👤 User Profile & Orders (`profile.html`, `my-orders.html`)**: View user account details, address book, active orders, and order history status.
- **🔑 Authentication (`login.html`)**: Sleek login and sign-up modal forms for user access.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6)
- **Frameworks & UI Components**: [Bootstrap 5](https://getbootstrap.com/)
- **Icons & Typography**: [Font Awesome 6](https://fontawesome.com/), [Google Fonts](https://fonts.google.com/) (*Playfair Display*, *Poppins*)
- **Animations**: [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- (Optional) VS Code with **Live Server** extension or Node.js / `http-server` for local hosting.

### Local Installation & Usage
1. **Clone the repository:**
   ```bash
   git clone https://github.com/AyushRana2203/FashionCart.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd FashionCart
   ```
3. **Launch the application:**
   - Open `index.html` directly in your web browser, **OR**
   - Use VS Code Live Server extension, **OR**
   - Run a quick HTTP server:
     ```bash
     npx http-server .
     ```
